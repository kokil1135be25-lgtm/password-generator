# 🔐 Password Generator

A simple and responsive **Password Generator** built with **React.js** and **Tailwind CSS**. It allows users to generate secure random passwords based on their preferred length and character options.

## 🚀 Features

* Generate random passwords instantly
* Adjustable password length from **6 to 100 characters**
* Option to include **numbers**
* Option to include **special characters**
* One-click **Copy to Clipboard**
* Displays a **"Copied!"** confirmation after copying
* Automatically generates a new password when the settings change
* Responsive and clean user interface

## 🛠️ Technologies Used

* **React.js**
* **JavaScript (ES6+)**
* **Tailwind CSS**
* **Vite**
* **HTML5**
* **CSS3**

## ⚙️ Getting Started

### 1. Clone the repository

```bash

```

### 2. Navigate to the project directory

```bash

```

### 3. Install dependencies


## 🔑 How It Works

The application uses React's state management and hooks to generate passwords dynamically.

Users can control:

* **Length** — determines the number of characters in the password.
* **Numbers** — adds numeric characters (`0-9`).
* **Characters** — adds special characters such as `!@#$%^&*()`.

The generated password can be copied directly to the clipboard using the **Copy** button.
